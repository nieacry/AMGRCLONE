# AMG rclone UI для Windows

1. Розпакуйте весь ZIP у постійну папку на комп'ютері.
2. Запустіть зовнішній **AMG rclone UI.exe**. Підпапки **app** і **release** зберігайте поруч із ним.
3. Натисніть **Підключити Dropbox** та увійдіть у потрібний акаунт у браузері. Business-вхід показує бізнес-папки цього акаунта, особистий — його особисті папки.
4. Оберіть окрему порожню локальну папку на NTFS. Файли з'являться у Провіднику як online-only та завантажуватимуться під час відкриття.
5. Для постійного зберігання файла або папки оберіть **На комп'ютері**. Закриття вікна ховає програму в трей; для виходу використовуйте **Вийти**.

У ZIP включено весь застосунок, Electron, rclone та нативний провайдер. Окремі Node.js, rclone, Visual C++ Runtime або Dropbox Desktop встановлювати не потрібно. Інтернет потрібен для входу й обміну файлами Dropbox.

Потрібна підтримувана 64-бітна Windows із Cloud Files API та локальна папка NTFS. Налаштування зберігаються в **Документи\AMGRCLONE**, незалежно від папки EXE. Для звичайного оновлення дивіться **UPDATING.uk.md**; профіль і локальні файли зберігаються.

Початкове отримання списку та підготовка плейсхолдерів виконуються у фоні. Налаштування залишаються доступними; підготовлені файли можна відкривати у Провіднику. Унизу видно поточний етап і кількість елементів. «Скасувати» зупиняє підготовку; «Оновити файли на вимогу» поновлює її. Правила «На комп’ютері» та «Лише онлайн» також застосовуються у фоні.

Файли лише онлайн показують повний хмарний розмір у Провіднику та діалогах видалення. Фактичне використання місця перевіряйте у рядку «На диску / Size on disk». Видалення синхронізованих файлів може видалити їх із Dropbox; для звільнення локального місця оберіть «Лише онлайн».

Скидання застосунку потребує підтвердження та не завантажує проєкт. Завантажені файли й локальні правки залишаються на диску; незавантажені плейсхолдери прибираються локально без видалення файлів Dropbox. Часткові завантаження та незавершені локальні копії збережено в Documents\AMGRCLONE\recovery. Для звичайного оновлення скидання не потрібне.
