# Оновлення AMG rclone UI для Windows

1. Дочекайтеся завершення поточної передачі файлів.
2. У меню значка програми біля годинника оберіть **Вийти**. Хрестик лише приховує вікно. Також можна скористатися **Налаштування → Вийти для оновлення**.
3. Розпакуйте ZIP нового випуску в окрему папку. Збережіть разом EXE і підпапки `app` та `release`.
4. Перейменуйте попередню папку програми, наприклад на `AMG rclone UI.previous`. Помістіть нову папку на її колишнє місце з колишньою назвою. Замінюйте папку цілком, без злиття старих і нових DLL.
5. Запустіть зовнішній `AMG rclone UI.exe`. Перевірте номер версії під логотипом, акаунти та стан синхронізації.

Профіль зберігається в **Документи\AMGRCLONE** вашого користувача Windows. Входи в Dropbox, правила, локальні корені, журнал і власні диски зберігаються при заміні папки програми. Не видаляйте профіль і не натискайте «Скинути застосунок» для звичайного оновлення. Локальні папки Dropbox теж залишайте на місці.

Перший запуск 0.15.0 переносить активний профіль зі старого `%APPDATA%\cloudlane`, якщо в Документах ще немає профілю. Старий каталог залишається резервною копією. Якщо новий профіль уже існує, він не перезаписується. Нова версія не працює одночасно зі старою.

Перед першим запуском іншої версії програма зберігає перевірений знімок робочого профілю в `Документи\AMGRCLONE\profile-backups`. Знімок містить зашифровані входи, базу з урахуванням SQLite WAL і стан незавершених операцій; файли проектів не копіюються. Це приватна копія для цього користувача Windows. Не додавайте її до загального ZIP випуску.

Резервна копія профілю не є резервною копією всього Dropbox. Не відновлюйте старий профіль поверх активної синхронізації й не запускайте довільну стару версію після зміни формату даних. Для звичайних багів встановлюйте наступний виправлений випуск тим самим способом. Якщо новий випуск відмовився відкрити профіль, збережіть його файли та повідомлення про помилку; скидання не є способом відновлення.

Рекомендовано зберігати постійний шлях папки програми: тоді ярлики залишаться чинними. Після запуску програма поновлює власний автозапуск на поточний EXE. Налаштування й дані не переносяться між різними користувачами/комп'ютерами простим копіюванням профілю: входи захищені Windows.
