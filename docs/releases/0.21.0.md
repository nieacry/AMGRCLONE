# AMG rclone UI 0.21.0

Велике оновлення про одне: жоден файл і жодна правка не губляться, навіть коли п’ятеро працюють в одному Dropbox одночасно. Оновлення — як завжди, заміною папки програми (`release\UPDATING.uk.md`). Профіль і входи в Dropbox зберігаються.

## Що ви побачите нового

**Конфліктні копії.** Якщо двоє змінили один файл, ваша версія більше не губиться і не «застрягає». Вона з’являється поруч як `ім’я (конфлікт, ІМ’Я-ПК, дата час).ext`, а оригінал отримує версію з Dropbox. Порівняйте обидві й залиште потрібну. Програма показує, скільки копій з’явилося за тиждень, і веде до них у журналі.

**Підтвердження великих видалень.** Якщо за раз зникає багато файлів (від 20 до 50 — залежно від розміру проєкту), програма питає:
- видалили в Dropbox → «Видалити в мене» або «Відновити в Dropbox». Поки ви не вирішите, на вашому комп’ютері нічого не зникає;
- видалили у себе в Провіднику → «Видалити в Dropbox» або «Повернути папку». Поки ви не вирішите, в інших нічого не зникає.

Рішення ухвалює кожен на своєму ПК. Невеликі видалення проходять як раніше, без питань.

**Карантин.** Завантажений файл, який видаляється або замінюється через синхронізацію, спершу копіюється в карантин на 30 днів (`Документи\AMGRCLONE\quarantine`). Кнопка «Відкрити карантин» є в банері. Щоб відновити — скопіюйте файл назад.

**Відновлення профілю.** Якщо файл налаштувань пошкодився, програма відкривається з резервної копії. Якщо входи не вдалося прочитати, папки й правила лишаються, і треба лише увійти в Dropbox знову.

## Що стало краще непомітно

- Тимчасові обмеження Dropbox («забагато запитів», збої сервера, обрив мережі) повторюються автоматично; нестача місця в Dropbox і недопустиме ім’я файла мають зрозумілі повідомлення.
- Видалення й перейменування в Провіднику більше не чекають, поки докачається закріплена велика папка.
- Зміни з Dropbox приходять за секунди, а не за хвилину; на великому проєкті програма значно менше навантажує диск і мережу.
- Вхід у Dropbox для нового облікового запису не блокує решту програми.
- Видалення облікового запису відкликає його вхід у Dropbox лише на цьому ПК; інших художників це не зачіпає.
- Виправлено: видалення папки в Провіднику не доходило до Dropbox; новий файл з ім’ям, яке вже є в Dropbox, зупиняв надсилання всіх інших; файли, видалені по одному (Shift+Delete), обходили підтвердження великих видалень.

## Перед оновленням

Оновлюйте спершу один комп’ютер, через день — решту. Дочекайтеся кінця передачі файлів і вийдіть через меню значка біля годинника.

# AMG rclone UI 0.21.0 (English)

One theme: no file and no edit gets lost, even with five people working in one Dropbox at the same time. Update as usual by replacing the app folder (`release\UPDATING.en.md`); the profile and Dropbox sign-ins are kept.

- **Conflict copies.** When two people edit the same file, your version is uploaded next to it as `name (конфлікт, PC-NAME, date time).ext`; the original takes the Dropbox version.
- **Large deletions need confirmation** (20–50 items depending on project size), in both directions: nothing disappears here, or for others, until you decide on your own computer.
- **Quarantine.** A downloaded file removed or replaced by sync is first copied to `Documents\AMGRCLONE\quarantine` for 30 days.
- **Profile recovery** from a backup copy instead of a failed start.
- Automatic retries for Dropbox limits and network errors; Explorer actions no longer wait for large pinned downloads; Dropbox changes arrive within seconds; lighter on large projects.
- Fixed: folder deletions in Explorer did not reach Dropbox; a name clash stopped all uploads; one-by-one deletions bypassed the confirmation.
