# 0.19.0 — швидкість на проєкті 100 ГБ (етап 4)

Стан: код готовий, автоматичні тести проходять; ручна перевірка нижче ще не виконана. Потрібно перезібрати helper (`scripts\test-build.cmd` або `npm run build:native`): додано команду `inspectMany`. Старий helper теж працює, але без пакетів.

## Що змінилося

- **Хмара.** Після повного списку клієнт тримає `list_folder/longpoll` з його курсором. Зміна в Dropbox запускає перевірку протягом ~5 с; без змін повний список запитується раз на 10–15 хв замість кожних 60–75 с. Якщо longpoll недоступний, діє старе правило 60–75 с.
- **Локальні зміни.** Скан перевіряє лише змінені шляхи (події файлової системи й helper). Повний обхід — на старті, після переповнення подій (понад 5000) і раз на 10–15 хв.
- **Пакетний `inspect`.** Стан локальних файлів читається пакетами по 512 шляхів.
- **Інше.** Пошук файла за `identity` під час завантаження — без перебору каталогу; перед знімком файла для надсилання перевіряється вільне місце (`err.diskFull`); заміри в діагностиці (`metrics`).
