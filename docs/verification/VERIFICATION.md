# Проверка прототипа, 01.11.2026

> Це історичний звіт для 0.1. Поточні результати 0.2: [VERIFICATION-0.2.md](VERIFICATION-0.2.md).

Среда: Windows, Node.js 24.11.0, Electron 45.2.1. Пакеты зафиксированы в package-lock.json. rclone 1.75.2 загружен с официального сервера, SHA-256 архива проверен: `8a9db2bad1dc79a65b3348fd857069598e2aab7cf4d118b77b1df23055aff818`.

## Результаты

- Production build и проверка TypeScript проходят.
- 15 тестов политик/валидации/парсинга OAuth проходят.
- Интеграционный тест с настоящим rclone проходит: lsjson читает кириллическое имя, bisync dry-run запускается, оба набора файлов и содержимое остаются неизменными. Использован локальный alias, не настоящий Dropbox.
- UI-сценарий в Electron проходит: дерево, правило отдельного файла, диалог плана, изоляция аккаунтов, поиск, добавление демо-аккаунта, компактный viewport без горизонтального переполнения.
- Настоящая настольная оболочка запускается с изолированным userData; мост доступен, Node.js в renderer недоступен, пустой аккаунт отображается, условия входа проверяются.
- Проверен roundtrip safeStorage через системное шифрование на Windows.
- Скриншот интерфейса просмотрен визуально. Данные на скриншоте демонстрационные.

## Что проверка выявила

У bisync имя служебного файла строится из двух путей. Длинная пара локальных путей на Windows привела к ошибке создания такого имени, несмотря на поддержку длинных полных путей. Тест использует короткий временный путь. Приложение сообщает об этой категории ошибки; поддержку длинных пар и безопасное сокращение служебных имён нужно решать отдельно, без самовольного переноса пользовательских папок.

Сеть и запуск внешних бинарников в ограниченном окружении проверки недоступны; установка и внешние процессы проверены с предоставленным доступом. Это свойство среды разработки, не требование к пользователю приложения.

## Не проверено

- Настоящий пользовательский OAuth Dropbox, листинг с действительными credentials, обновление и отзыв настоящего refresh token.
- Работа на macOS, Keychain на Mac, подписанная сборка и установщики.
- Перенос/удаление облачных файлов и фоновая синхронизация — отсутствуют в 0.1.
- Cloud Files/File Provider и открытие placeholder внешним приложением — отсутствуют в 0.1.

`npm audit --omit=dev`: 0 замечаний. Полный `npm audit`: 15 moderate замечаний в транзитивных зависимостях electron-builder, связанных с minimatch/обработкой шаблонов. Упаковщик не входит в runtime. До выпуска необходимо обновить/заменить цепочку упаковки и повторить аудит; предложенный npm downgrade старого упаковщика автоматически не применялся.
