# Перевірка 0.15.2 · Windows

Нативна таблиця має чотири окремі стовпці: Назва, Стан, Правило, Розмір. Фактична доступність і бажане правило показані в одному горизонтальному рядку; повтор «Правило:» прибрано. Висоту рядка зменшено з 54 до 36 px. Власна буква диска залишається поруч із правилом без перенесення на наступний рядок. Довгі значення мають tooltip і ellipsis; відкриті властивості не приховують окремий стовпець стану.

Збірка TypeScript/Vite пройшла. Існуючий storage smoke перевіряє реальні online-only/cache/pinned переходи та перезапуск, обидві мови, вузьке вікно 1000×760, окремі заголовки, вирівнювання стовпців і висоту кожного рядка не більше 38 px. Source screenshot переглянуто візуально. Тестові файли та профілі ізольовані; налаштування і файли користувача не змінювалися.

Зміна стосується розміщення таблиці. Формат профілю, схема SQLite, правила зберігання та операції синхронізації не змінені.
