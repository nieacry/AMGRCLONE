# Перевірка 0.14.1 · 01.11.2026

Зміна: діалог online-only показує вже збережений локальний шлях і дає змогу ввімкнути провайдер для нього без повторного OS folder picker. Окрема кнопка зберігає вибір іншої папки. Обидва маршрути використовують ту саму перевірку порожнього кореня, перекриття інших коренів та історії попереднього bisync; Windows helper перевіряє NTFS. Непорожні папки не очищаються. Скасування альтернативного вибору більше не від’єднує невдалий порожній native root.

Регресійний packaged сценарій перевіряє: відмову для непорожнього збереженого кореня зі збереженням файла/режиму, скасування picker зі збереженням шляху, успішне ввімкнення в уже вибраній порожній папці без виклику picker, створення справжнього placeholder і читання вмісту. Попередні перевірки subst, власності, трея, рестарту й pin/unpin залишаються в тому самому сценарії. Скриншот діалогу: test-results/native-root-0.14.1.png.

Для випуску виконуються production build, перевірка UK/EN словників і файлових guard, UI smoke та packaged smoke. Базові результати 37 тестів і нативних перевірок — VERIFICATION-0.14.0.md. Межі готовності не змінилися: справжній Dropbox native transport і робочі редактори потребують наскрізних випробувань; macOS File Provider відсутній.
