# 0.18.0 — п’ятеро працюють одночасно (етап 3)

Стан: код готовий, автоматичні тести проходять; ручна перевірка нижче ще не виконана.

## Що змінилося

- **Окрема черга завантаження.** Закріплення («Завжди на цьому пристрої») завантажує файли в окремій черзі, до 2 файлів одночасно. Перевірки, надсилання, видалення й перейменування в Провіднику більше не чекають, поки докачається велика папка. Раніше кожен закріплений файл тримав спільну чергу до 24 годин.
- **Черги на обліковий запис.** Дії різних облікових записів виконуються паралельно. Вхід у Dropbox (вікно браузера до 5 хв) і старт без мережі більше не блокують програму.
- **Скасування.** Кнопка «Скасувати» зупиняє лише синхронізацію; раніше вона могла зупинити вхід у Dropbox або оновлення токена іншого облікового запису.
- **Опитування Dropbox** — раз на 60–75 с (випадково для кожного циклу), щоб 5 комп’ютерів не звертались одночасно.
- **Діагностика** містить ім’я комп’ютера й користувача Windows.
