# Перевірка 0.14.3

Виправлено блокування виходу/reset, коли користувач вручну видалив локальний native root. Раніше повторне підключення повертало загальний HRESULT 0x80070005; тепер відсутній шлях розпізнається перед запуском helper і відображається окремою помилкою.

Кнопка відключення доступна для native-акаунтів. Backend вимагає явне підтвердження: для наявного root завантажує та перетворює власні placeholders на звичайні локальні файли; для відсутнього — зберігає metadata/catalog та залишок кешу в userData/recovery без токенів. Порожній root не створюється; невідомий або переміщений root не unregister примусово. Власні subst відключаються за перевіркою цілі; стороння буква не змінюється. Інші акаунти залишаються підключеними. Reset не видаляє recovery, де можуть бути єдині локальні копії незавершених змін.

Очистка старих маркерів більше не потребує запущеного helper, використовує окремий revision-aware транспорт і підтримує скасування. Автоматична очистка не затримує відключення акаунтів із незавершеним reset.

Перевірки: 3 нові account-recovery tests (збереження кешу без конфігурації/токенів, відмова для наявного кореня, detach відсутнього root без helper/server writes), 18 релевантних unit/integration tests; source та packaged logout smoke для трьох сценаріїв: відсутня папка, наявна папка з online-only/unsent даними/власним диском та повний reset із відсутньою папкою. В onboarding smoke повторно перевіряються automatic online-only, marker cleanup, checkbox layout і reset після невдалої hydration. Базові результати 42 перевірок 0.14.2 залишаються історичними; звичайний bisync у цьому випуску не змінювався.

Межі: recovery автоматично не імпортується; переміщені roots потребують повернення за старим шляхом або окремої процедури відновлення. Цей механізм не повертає вже видалені користувачем файли. macOS File Provider не реалізовано.

Пакування: зовнішній C++ launcher із версією та іконкою запускає app/AMG rclone UI.exe через CreateProcessW без shell; корінь містить тільки цей EXE й підпапки app та release. Metadata/source.zip перенесено в release. Launcher smoke запускає справжній GUI з шляху з українськими літерами/пробілами, перевіряє передачу аргументу remote-debugging-port на loopback та очищення ELECTRON_RUN_AS_NODE, читає версію й bundled rclone в ізольованому профілі. Наступні UI тести підключаються напряму до inner Electron для діагностики. Publish замінюється цілком, старі runtime файли не залишаються в ньому.

Заголовок початкового екрана змінено на «Підключення Dropbox» (EN: Dropbox connection) за уточненням користувача.
