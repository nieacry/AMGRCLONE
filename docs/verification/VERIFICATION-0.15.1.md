# Перевірка 0.15.1 · Windows

У списку нативних файлів фактичну доступність відокремлено від бажаного правила. Основні стани: «Лише онлайн», «Завантажено в кеш», «Закріплено локально»; правило показано окремим рядком. Для папок агрегується вибране піддерево, включно зі згорнутими гілками. Є частково завантажений і порожній стани; невідомі дані та конфлікти не видаються за локальні копії. Поточні передачі мають окремий стан синхронізації.

Новий read-only IPC повертає лише запитані шляхи поточного акаунта, до 1000 за виклик, з перевіркою вводу. Видимі файли перевіряються через Cloud Files attributes, без читання вмісту або виклику hydration. Паралелізм перевірок обмежено чотирма. UI оновлює показання раз на 1,5 секунди, не застосовує відповіді від попереднього акаунта та не змінює правило при відкритті файла. Цей механізм працює і при паузі фонової синхронізації. Завершення hydration оновлює каталог, а pin без повного вмісту не видається за завершене локальне закріплення.

Пройдено 65 unit/integration tests. Нові тести покривають фізичний стан проти pin intent, агрегування папок, вкладені гілки, конфлікти, активні передачі, query bounds, ізоляцію акаунтів і перевірку під час паузи без зміни правила. Пройдено native/provider smoke: hydration, pin/dehydrate, dirty-захист, upload, rename/delete, конфлікти, reconnect і повтор detach після невдалої hydration.

Source і packaged storage smoke відтворюють сценарій користувача на справжньому NTFS placeholder: зовнішній Node-процес відкриває файл, Windows завантажує bytes через провайдер, UI переходить з online-only у кеш. Фонову синхронізацію під час відкриття призупинено. Правило залишається online-only; папки показують змішану доступність. Після перезапуску застосунку/провайдера файл залишається кешованим. Перевірено pin/free-space переходи, три українські та англійські назви одночасно, вузьке вікно без горизонтального переповнення й screenshot. Тестовий профіль безпечно скинуто зі збереженням звичайних локальних bytes.

На випусковій збірці пройдено оновлення з 0.14.5: входи, правила, Documents-профіль, native owner, driveOwner, власний subst, історія, незавершене видалення та налаштування старту збережені. Пройдено packaged recycle: pinned/online/folder, permanent delete, orphan і offline retry після restart. Пройдено desktop smoke: автоматичний нативний старт, захист непорожньої папки, власні диски, tray/minimized і restart. Вміст runtime фінального архіву порівнюється з перевіреним кандидатом; publish і versions мають окремі контрольні суми.

Межі: транспорт у destructive smoke — локальний adapter; живі Dropbox-акаунти та файли користувача не використовувалися. Фізичне перезавантаження Windows не виконувалося — перевірено перезапуск процесів і збереження bytes на NTFS. Правило online-only дозволяє звільнення кешу, а локальне закріплення є окремим наміром. Формат профілю, мінімальна сумісна версія 0.15.0 і схема SQLite не змінювалися.
